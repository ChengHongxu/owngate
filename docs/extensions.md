# 扩展导入

后台「扩展」可以安装自己的声明式 HTTP 接口。支持原生 YAML / JSON 清单和 OpenAPI 3.0；导入过程只解析粘贴内容，不读取本地文件、不请求文档中的 URL、不执行 JavaScript / TypeScript。

## 操作步骤

1. 打开「扩展」，选择格式并粘贴接口定义。OpenAPI 必须填写连接器 ID，原生清单可沿用 `connector`。ID 需要以小写字母开头，共 3 到 64 个小写字母、数字、下划线或短横线。
2. 点击「预览操作」，核对方法、路径和只读语义。预览中的能力全部禁用；仅通过检查的 GET 查询可以勾选。写操作、带请求体或名称疑似有副作用的 GET，以及未知浏览器站点不能启用。
3. 明确勾选本次需要的查询，安装时完成二次验证。修改源文档会清空预览；服务器安装时也会重新编译并核对指纹。
4. 到「连接」选择刚安装的服务，配置站点与授权。令牌和密码在这里单独填写，不要粘贴到扩展定义里。原生清单通过 `{{secret.access_token}}` 等模板引用授权字段。
5. 选中的能力初始显示「待验证」。可在能力弹窗填写参数后试查，或授予客户端权限后调用；只有实际成功的查询才显示「可用」。未选中的查询和所有写操作不能借助验证接口启用。

GET 方法与路径名称只能辅助检查。导入前仍须阅读站点文档，确认被选中的操作只读取数据。


## 下一步

安装前对照[格式与限制](reference/extensions.md)，需要自定义结果布局时阅读其中的展示声明。后台粘贴导入不安装代码，仓库维护者开发代码适配器可参考[可信 TypeScript 示例](../connectors/paged-json-example/README.md)。

通过测试夹具并不代表第三方站点已经兼容；安装后先验证所需能力，再授予客户端最小范围权限。返回[文档导航](README.md)。
