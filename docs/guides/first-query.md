# 完成第一次查询

完成本指南后，你会有一个已验证的连接，以及只能读取指定能力的客户端。

先按[部署指南](../../deploy/README.md)启动服务，用配置的 `OWNGATE_ORIGIN` 地址打开后台。正式使用需要受信任的 HTTPS 域名；本机 `http://localhost:3000` 也支持 Passkey。

## 创建管理员

首次访问时创建唯一管理员，再到安全设置配置 Passkey 或 TOTP。TOTP 可以使用验证器 App 扫描二维码；无法扫码时展开手动添加。

管理员会话用于连接、凭据和授权管理，客户端令牌用于数据读取，两者分别认证。敏感操作会要求二次验证；配置 Passkey 后按页面提示使用 Passkey。

## 添加并验证连接

1. 在「连接」中添加一个服务，填写名称、配置和授权信息。
2. HTTP 连接填写该平台要求的访问令牌。New API 默认使用普通用户角色，只有明确需要且站点令牌允许时才选择管理员角色。
3. 浏览器连接打开远程登录，在受管 Chromium 中完成站点登录；已有 Cookie 时也可在连接详情导入。
4. 点击「验证连接」，再找到你需要的能力，点击「试一下」。有必填参数时填写后查询。
5. 核对结果、单位和更新时间；失败时展开执行过程，查看实际失败节点与原因。

「待验证」表示还没有这项能力的有效成功证据；「适配异常」表示实现或响应解析需要处理；「暂不可用」可能来自网络、限流或站点错误。「需要重新登录」应由授权验证查询的实际认证失败触发。一个公开接口成功并不能证明账户已经登录，整体验证成功也不等于每项能力都已测试。

远程登录操作的是服务器浏览器。Windows Edge 中的网站会话不会自动同步，网页画面也不能把 Windows Hello 转发给外站。站点要求 Passkey 时，可选择该站提供的扫码、短信或 TOTP 等方式；没有其他方式时需要调整站点登录流程，不能绕过验证。

## 创建只读客户端

1. 打开「客户端」，填写名称和有效期，创建客户端并保存一次性显示的令牌。
2. 为该客户端选择刚创建的连接，只勾选需要的能力和字段范围，再保存权限。
3. 检查客户端授权总览，确认没有额外连接或敏感字段。
4. 打开「接入方法」，选择 MCP、HTTP API 或 CLI，按生成的配置接入。

创建令牌不会自动授予任何连接权限。不要把管理员会话、网站密码或 Cookie 放入 Agent 提示词，也不要把客户端令牌嵌入公开网页。

接着按[客户端接入](connect-clients.md)完成程序调用。若服务运行正常而查询失败，先在能力详情查看错误，不要通过高频重试突破平台冷却期或风控限制。
