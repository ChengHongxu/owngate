# 架构与信任边界

OwnGate 将网站账户访问集中到自托管服务，再用独立客户端身份输出获准数据。网站凭据与客户端令牌分别管理：前者访问上游，后者仅授予 OwnGate 的查询权限。

## 调用路径

Web 后台使用管理员会话，REST、MCP 和 CLI 使用客户端令牌。CLI 调用 REST，其 stdio MCP 命令转发服务器的 MCP 端点。各数据入口汇入 `packages/core` 的统一调用流程，执行认证、授权、输入校验、连接策略、缓存、调度、输出过滤与审计。

结果信封区分成功、部分成功与错误，同时保留来源、字段可见状态、单位和时间。未知值不能用零替代，部分条目失败不能改报完整成功。任务与缓存复用业务结果，但读取时仍按当前授权过滤，撤权与令牌过期会影响后续读取。

连接器清单声明配置、凭据字段、能力输入输出，以及可选的展示、验证与组合视图。前端根据声明生成表单和结果展示，连接器专属业务不应该通过页面中的 ID 分支实现。详情见[扩展格式](../reference/extensions.md)。

## 进程边界

| 组件 | 职责 | 边界 |
|---|---|---|
| `apps/server` | Fastify 后台、REST、MCP、授权、调度、审计、凭据代理 | 持有数据库和主密钥，唯一对外服务入口 |
| `apps/web` | React 管理后台 | 管理员会话认证，不代替客户端授权 |
| `apps/browser` | Playwright 会话、远程登录、站点响应采集 | 每连接持久 profile，生产仅通过 egress 出网 |
| `packages/runtime-http` | 声明式 HTTP 执行和可信适配器 | 生产为独立容器，控制进程与无特权子进程分离 |
| `services/egress-proxy` | 浏览器域名、地址与租约控制 | 校验连接代理密码，拒绝私网/特殊地址及 DNS 重绑定 |
| `apps/cli` | 客户端命令、stdio 桥接、离线维护 | 维护命令要求停止 server 并取得数据库租约 |

浏览器 profile 持有站点 Cookie。Windows 本地浏览器和服务器受管浏览器是不同会话，远程网页画面不等于实体认证器转发。

HTTP runtime 不持有数据库、主密钥或业务凭据；请求通过 server 的受限代理注入凭据，能力路径和只读方法受到限制。代码适配器作为可信源码随镜像发布，容器隔离不代表可以接收任意用户代码。

## 持久数据

SQLite 存储连接、客户端授权、任务、监控、扩展与审计。凭据和任务内容等敏感字段采用逐记录信封加密，密文绑定记录与字段；主密钥与数据库需要分别保管。浏览器 profile 作为独立敏感数据保存，不因数据库加密而自动得到保护。

持久任务使用租约与恢复机制，提交成功仅表示进入队列。取消正在执行的调用不能证明远端已停止；无法确认的结果保留相应状态。监控计划使用 UTC，停机期间的计划不追补。

## 状态证据

能力状态属于具体能力，配置或登录态改变后需要重新验证。指定授权验证能力的失败可以阻断连接认证，普通查询的认证失败只影响自身；公开能力成功不证明私有账户已经登录。并发观察采用版本和序列约束，防止旧查询覆盖较新的状态。

管理员查询可获得有界执行轨迹帮助诊断；轨迹不作为普通客户端业务数据返回，也不进入共享缓存。来自网站的文本始终是数据，不能作为 Agent 的可信指令。

## 源码分布

`packages/core` 管理统一调用与类型，`packages/db` 管理 SQLite，`packages/vault` 管理加密，`packages/connector-runtime` 编译清单与扩展，`packages/browser-runtime` 管理浏览器基础设施，`packages/schema-meta` 导出 Schema 元数据。内置平台声明位于 `connectors`。

当前产品边界见[产品范围](product-scope.md)，修改工程见[贡献指南](../../CONTRIBUTING.md)，运行与恢复见[部署](../../deploy/README.md)。
