# 产品范围与实现边界

OwnGate 面向个人用户管理自己有权访问的网络账户与服务。一个管理员维护连接，多个受限客户端读取数据。产品目前处于开发阶段，没有多租户隔离、组织协作或公开互联网服务的部署承诺。

## 已实现的路径

管理员可以通过 Web 添加连接、保管凭据、执行受管浏览器登录、测试能力，再按连接、能力和字段范围授权客户端。客户端通过 REST、MCP 或 CLI 读取结果；长查询可以提交持久任务，结果在读取时重新检查当前权限。

New API 提供用户与管理员角色的只读查询。社交连接器通过受管浏览器自然产生的响应读取账户资料及已声明的内容能力，不承诺任意网站通用自动化。扩展导入支持受限 HTTP 清单和 OpenAPI 3.0，不接受任意代码上传。

监控支持 UTC 五字段 cron、条件判定和 SMTP 通知；停机错过的周期不补跑。动作提案可供人工审查，但生产站点写执行仍然关闭，客户端不能通过提案工具批准或执行写入。

## 实测不等于通用兼容

历史开发验证曾在特定已登录实例上取得 New API 六项个人查询、Bilibili 与知乎账户资料，以及部分关注或推荐内容的结果。社交内容中存在未知字段或无法解析的条目，返回 `partial` 而非完整成功。这些观察只覆盖当时的站点部署、账户与接口版本，不代表当前部署、其他 fork 或所有能力已通过验收。

以下范围仍需在实际目标环境独立验证：

- New API 管理员能力与其他 fork；小红书、X 及站点接口变化后的能力。
- 手机扫码、会话过期与风控后的人工恢复、实体 Passkey / Windows Hello。
- 真实连接经客户端权限链路的端到端查询；真实 SMTP 投递。
- 长期运行、HTTPS 证书信任、进程托管、备份恢复与主密钥维护演练。

自动化覆盖包括单元测试、本地 HTTP/SMTP 集成、合成页面及真实 Chromium、一次性生产容器。真实浏览器可以加载合成页面，所以“使用 Chromium”本身不能证明第三方账户或平台接口可用。检查方法和证据范围见[测试指南](../guides/testing.md)。

## 对外部应用的责任划分

OwnGate 提供数据与授权，不负责托管 Agent 生成的界面、桌面置顶、跨 MCP 数据组合或脱离会话的运行容器。外部应用可在可信宿主中复用已认证 MCP 会话或 HTTP 客户端，将获准结果传递给自己的 UI。

平台网站可能有缓存、冷却期、日预算和限流。跳过 OwnGate 缓存不意味着上游实时更新；浏览器平台的风控或 429 可能导致持久暂停，需要管理员检查后恢复。
